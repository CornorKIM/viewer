# runner — 게이트

> 계약: `docs/spec/sf-daily/spec/runner.md`
> 구현: 이 폴더 · 시험 결속 규약: `tests/lib/README.md`
> 두 자리에서 잰다. 서비스 프로세스(`node sf-daily/main.js`)는 시작 거부 · 떠 있음 · 회차 간격 · 표준 출력을, 회차 하나씩은 `createRunner(deps)` 에 가짜 시계와 가짜 이음새(`world.js`)를 주어 잰다.
> 회차 시험의 가짜 계획(KST): A 로그인 10:30:10 · B 10:40 · C 10:50 · D 11:00 · CDR 10:10, 조회 · 로그아웃은 `world.js` 의 PLAN. 회차는 따로 적지 않으면 30초마다다.

## 명제

### RN-01. SF_DAILY_ENABLED 가 true · false 가 아니면 시작하지 않는다

- **등급**: 핵심
- **겨누는 조항**: 1절 「설정 표의 시작 거부 조건 중 하나라도 걸리면 … 걸린 설정 이름을 모두 출력하고 0 이 아닌 코드로 끝난다」 · 설정 표 `SF_DAILY_ENABLED`
- **판정**: 값이 `yes` · `TRUE` · `1` 이면 15초 안에 0 이 아닌 코드로 끝나고 출력(표준 출력 · 오류 출력)에 `SF_DAILY_ENABLED` 가 있다.
- **구현 상태**: 미구현 — `tests/sf-daily/runner/process.test.js::RN-01`
