# docs

- `spec/` — 구현이 읽는 계약. 모듈마다 무엇을 보장하는가와 모듈 사이 이음새가 있고, INDEX 사슬로 찾는다.
- `ops/` — 설치 · 운영하는 사람을 위한 문서. 배포 절차, 고장 대응, 프로젝트 위험(hazards.md)이 여기 있다.
- `external/` — 팀 밖에서 받은 문서와 팀 밖에 주는 문서. 사업관리시스템 로그수집 API 연동가이드 · 규격서 같은 원문이 여기 있다.
- `design/` — 사람과 나눈 설계 대화 기록. 대화 하나에 파일 하나로, 무엇을 왜 정했고 무엇을 기각했는지 담는다.
- `runs/` — 무인 실행 하나에 결과 보고 하나. 실행의 최종 판정은 여기에만 있다.
