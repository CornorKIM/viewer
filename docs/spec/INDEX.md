# docs/spec 색인

- [ARCHITECTURE.md](ARCHITECTURE.md) — 제품 트리, 모듈 경계, 이음새 방향, 공통 규칙의 소유자. 모듈을 새로 만들거나 어느 모듈이 무엇을 책임지는지 찾을 때 읽는다.
- [GLOSSARY.md](GLOSSARY.md) — 도메인 낱말(영업일 · 단계 · 정상 저장 등)과 문서가 쓰는 말. 계약의 낱말 뜻이 헷갈리거나 계약을 쓰기 전에 읽는다.
- [sf-daily/](sf-daily/INDEX.md) — 영업일 자동 로그 전송과 23시 현황 메일을 맡는 서비스의 모듈 계약. 자동 전송 · 휴일 판단 · 하루 계획 · 메일 동작을 바꾸거나 구현할 때 읽는다.
- [interfaces/](interfaces/INDEX.md) — 산출물 사이 이음새와 제품 밖 계약(로그수집 API, 휴일 달력, 메일 서버, 공유 전송 이력). 외부 시스템과 주고받는 모양이나 공유 테이블을 건드릴 때 읽는다.
