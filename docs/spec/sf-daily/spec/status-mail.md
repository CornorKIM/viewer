# status-mail — 현황 메일은 그날 업체별 단계 정상 저장 건수를 보이고 로그인 0 을 경고한다

> 상태: 사람 확정 · 독자: 구현자 / 오케스트레이터
> 산출물: sf-daily
> 이음새: 현황 메일 보내기 → `sf-daily/api/status-mail.md` · 전송 이력 → `interfaces/sf-log-history.md` · 메일 서버 → `interfaces/smtp-mail.md` · 업체 명부 → `sf-daily/spec/companies.md`
> 단언: 같은 자리의 `tests/sf-daily/status-mail/GATES.md`

## 목적 / 의도

그날 다섯 업체가 로그인 · 조회 · 로그아웃을 몇 번 정상 저장했는지 메일 한 통으로 알린다. 로그인이 0 인 업체는 사람이 수동으로라도 로그인하도록 눈에 띄게 경고한다. 같은 그날의 현황 메일은 한 번만 나간다.

## 언어 · 런타임

Node.js(ES 모듈).

## 의존 도구 · 시스템

- 전송 이력(Windows PostgreSQL 의 기존 테이블) — `interfaces/sf-log-history.md`.
- sf-daily 전용 DB — 그날 메일을 보냈다는 기록.
- 메일 서버(제품 밖) — `interfaces/smtp-mail.md`.
- 업체 명부 — `sf-daily/spec/companies.md`.

## 입력

- 그날(KST 날짜) 하나.
- **설정**
  - `SMTP_HOST`(필수) · `SMTP_PORT`(기본 587) · `SMTP_USER`(필수) · `SMTP_PASS`(필수) — 메일 서버 접속. 필수가 비어 있으면 runner 가 시작하지 않는다.
  - `SF_REPORT_TO`(필수) — 받는 사람 주소. 쉼표로 여럿. 비어 있거나 주소 모양이 아닌 값이 있으면 runner 가 시작하지 않는다.
  - `SF_REPORT_LINK`(기본 `https://twin.smartline.kr/sflog.html`) — 메일에 넣는 이력 화면 주소.

## 출력 (계약)

1. **현황 메일 한 통**: `SF_REPORT_TO` 의 받는 사람 모두에게.
2. **보내기 결과**: 보냄 · 이미 보냄 · 실패 중 하나. 모양은 `sf-daily/api/status-mail.md`.

## 핵심 로직 (동작)

### 1. 메일 본문은 업체마다 한 줄이다

- **본문 표의 줄은 업체 명부의 다섯 업체이고 순서도 명부의 순서다.**
- **줄마다 업체 이름 · 유형 · 로그인 건수 · 조회 건수 · 로그아웃 건수가 있다.**
- **건수는 그날 그 업체 · 그 단계의 정상 저장 건수다.** 셈은 `interfaces/sf-log-history.md` 가 정한다.

  자동 전송 · 뷰어 화면 로그인 · Vercel 쪽 전송을 모두 센다. 사람이 수동으로 로그인한 것도 건수에 든다.

### 2. 로그인 건수가 0 인 업체는 두 곳에 드러난다

- **로그인 건수가 0 인 줄은 빨간색으로 표시된다.**
- **로그인 건수가 0 인 업체가 하나 이상이면 본문 맨 위에 「수동 로그인 필요:」 와 그 업체 이름들이 나온다.**
- **로그인 건수가 0 인 업체가 하나 이상이면 제목 앞에 「[로그인 누락]」 이 붙는다.**
- **로그인 건수가 0 인 업체가 없으면 본문 맨 위에 「모든 업체 로그인 정상」 이 나온다.**

### 3. 제목과 링크

- **제목은 「스마트공장 로그 현황 YYYY-MM-DD」 이고 날짜는 그날이다.**
- **본문에 `SF_REPORT_LINK` 주소가 들어 있다.**
- **본문에 인증키 · 메일 계정 비밀번호가 들어 있지 않다.**

### 4. 같은 그날의 현황 메일은 한 번만 나간다

- **그날 현황 메일을 이미 보냈으면 다시 요청해도 보내지 않고 「이미 보냄」 을 돌려준다.**
- **서비스가 다시 시작된 뒤에도 같은 그날은 다시 보내지 않는다.**
- **메일 서버가 받지 않았으면 「실패」 를 돌려주고 보낸 것으로 치지 않는다.**

  실패한 메일은 runner 가 그날 안에 다시 요청한다.

## 이 모듈에 없는 것

- 언제 보내는가 · 영업일에만 보내는가 — `runner`.
