# 사업관리시스템 로그수집 API

> 방향: sf-daily(step-sender) → 사업관리시스템
> 소유: 제품 밖 · 종류: 「제품 밖 · 읽기 전용」(출처: 로그수집 API 연동가이드 v1.6 · 연동규격서 v1.7)
> 상태: 동결 · 사람 확정

우리가 기대는 부분만 적는다. 원문과 충돌하면 원문이 이긴다.

## 목적

로그 한 건을 보내고 저장 결과를 받는다.

## 표면

요청: `POST https://log.smart-factory.kr/apisvc/sendLogData.json`, 본문 `application/x-www-form-urlencoded; charset=UTF-8`.

| 필드 | 필수 | 뜻 |
|---|---|---|
| `crtfcKey` | 예 | 업체 인증키 |
| `logDt` | 예 | 로그 일시 `YYYY-MM-DD HH:MI:SS.SSS`(23자, KST) |
| `useSe` | 예 | 사용 구분 코드 |
| `sysUser` | 예 | 시스템 사용자(60자 이하) |
| `conectIp` | 예 | 접속 IP(30자 이하) |
| `dataUsgqty` | 예 | 데이터 사용량(정수, 없으면 0) |

사용 구분 코드 중 우리가 쓰는 것:

| 코드 | 뜻 |
|---|---|
| DO6001 | 로그인 |
| DO6002 | 로그아웃 |
| DO6003 | 데이터 조회 |
| DO6999 | 테스트(통계 제외) |

응답: JSON. 결과는 `result.recptnRsltCd`(결과 코드) · `result.recptnRslt`(문구) · `result.recptnRsltDtl`(상세) · `result.recptnDt`(수신 시각). `result` 가 없으면 같은 이름이 최상위에 있다.

## 오류

결과 코드 중 우리 동작이 기대는 것:

| 코드 | 뜻 | 우리 쪽 |
|---|---|---|
| AP1002 | 정상 저장 | 정상 저장 |
| AP1027 | 로그 일시가 오늘이 아님 | 오류 응답 |
| AP1029 | 10분 이내 재전송 — 수신만, 미저장 | 오류 응답 |
| AP1003 · AP1011 | 인증키 불일치 · 없음 | 오류 응답 |
| AP1030 | 수집 미대상 · 수집기간 종료 | 오류 응답 |
| AP1031 · AP1032 | 하루 요청 5,000건 · 성공 144건 초과 | 오류 응답 |

그 밖의 코드도 AP1002 가 아니면 모두 오류 응답이다.

## 순서 · 중복

- 같은 인증키로 10분 안에 온 두 번째 로그는 저장되지 않는다(AP1029). 이 제한은 인증키마다 따로다.
- 보낸 로그를 조회하는 API는 없다.

## 불변식

- 저장되는 로그는 당일 로그뿐이다.
