# interfaces 색인

산출물 사이 이음새와 제품 밖 계약. 제공하는 쪽이 소유하고, 제품 밖 계약은 「제품 밖 · 읽기 전용」 으로 우리가 기대는 부분만 적는다.

- [sf-log-history.md](sf-log-history.md) — 공유 전송 이력 테이블 두 개의 모양, 자동 전송 행 구별, 그날 정상 저장 건수의 셈. 이력을 쓰거나 세는 코드를 만들 때 읽는다.
- [sf-log-api.md](sf-log-api.md) — 사업관리시스템 로그수집 API 의 요청 필드, 사용 구분 코드, 결과 코드와 10분 제한(제품 밖). 로그를 보내는 코드를 만들거나 결과 코드 처리를 바꿀 때 읽는다.
- [kr-holiday-calendar.md](kr-holiday-calendar.md) — 구글 「대한민국의 휴일」 iCal 의 주소와 공휴일 · 기념일 구분(제품 밖). 휴일 판단을 구현하거나 휴일 출처를 바꿀 때 읽는다.
- [smtp-mail.md](smtp-mail.md) — 현황 메일을 넘기는 메일 서버 접속과 성공 판단(제품 밖). 메일 보내기를 구현할 때 읽는다.
