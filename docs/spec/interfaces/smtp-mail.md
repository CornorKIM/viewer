# 메일 서버

> 방향: sf-daily(status-mail) → 메일 서버
> 소유: 제품 밖 · 종류: 「제품 밖 · 읽기 전용」(출처: Gmail SMTP)
> 상태: 동결 · 사람 확정

우리가 기대는 부분만 적는다. 원문과 충돌하면 원문이 이긴다.

## 목적

현황 메일 한 통을 받는 사람에게 넘긴다.

## 표면

- 접속: `SMTP_HOST`:`SMTP_PORT`, STARTTLS 뒤 `SMTP_USER` · `SMTP_PASS`(앱 비밀번호)로 인증.
- 보내는 사람: `SMTP_USER`.
- 메일: UTF-8 HTML 본문, 제목 UTF-8.

## 오류

| 조건 | 우리 쪽 |
|---|---|
| 접속 · STARTTLS · 인증 실패 | 실패(재시도 가능) |
| 받는 사람 중 하나라도 거부 | 실패(재시도 가능) |

## 불변식

- 서버가 DATA 를 받아들였으면(250) 보낸 것이다.
