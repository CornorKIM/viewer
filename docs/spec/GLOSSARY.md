# 용어집

## 도메인 낱말

| 낱말 | 뜻 |
|---|---|
| 업체 | 로그를 보내는 단위. 유형2-3 목공소봄(A) · 이레공방(B) · 브랜드스미스(C) · 비스트럭처(D), 유형1 (주)씨디알시스템(CDR). 업체마다 인증키가 하나 있다. |
| 유형 | 업체가 속한 사업 구분. 유형1 · 유형2-3. 유형마다 전송 이력 테이블이 다르다. |
| 사업관리시스템 | 로그를 받는 쪽(스마트공장 로그수집 API). |
| 단계 | 하루 과정의 한 칸. 로그인(DO6001) · 조회(DO6003) · 로그아웃(DO6002). |
| 정상 저장 | 사업관리시스템이 결과 코드 AP1002 로 답한 전송. |
| 그날 | 한국 시간(KST) 기준 날짜 하나. |
| 영업일 | 월~금이면서 공휴일이 아니고 5월 1일이 아닌 그날. |
| 공휴일 | 휴일 달력에서 설명이 「공휴일」 인 날. 대체공휴일 · 임시공휴일 · 선거일을 포함한다. 「기념일」 은 공휴일이 아니다. |
| 하루 계획 | 업체 하나 · 그날 하나에 대해 단계마다 정한 보낼 시각. |
| 전송 이력 | 보낸 로그와 응답을 남기는 공유 테이블. 자동 전송 · 뷰어 화면 로그인 · Vercel 쪽 전송이 함께 쓴다. |
| 현황 메일 | 영업일 23시에 보내는 그날 업체별 단계 정상 저장 건수 메일. |
